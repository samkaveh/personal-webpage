A small Rust physics engine, with Python at the door.

In this talk I showed how I built a small Rust physics engine with Python integration. What started as a weekend side project evolved into a deep dive into high-performance bridge technologies between systems languages and the data-science ecosystem.

We looked at memory, maths, and what it actually takes to make a simulation feel alive — then compiled the whole thing to the web with WebAssembly.
